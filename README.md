# Python Student Database (SQLite)

## Description

This project is a Python application that uses SQLite to manage student records. It allows users to add, view, search, update, and delete student information using a local database.

## Features

- Add student records
- View all students
- Search for students
- Update student records
- Delete student records

## Technologies Used

- Python 3
- SQLite (`sqlite3`)

## Concepts Practiced

- SQLite databases
- SQL queries
- CRUD operations
- Functions
- User input
- Exception handling

## Future Improvements

- Add a graphical user interface (GUI)
- Export records to CSV
- User login and authentication
- Connect to a web application
